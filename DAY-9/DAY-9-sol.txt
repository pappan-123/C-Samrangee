DETAILED EXPLANATIONS & TRAP DISSECTIONS:

Q1. Correct Answer: B (10 followed by 20)
    - TRAP EXPLAINED: The post-increment operator (ptr++) evaluates to the *current* address first, dereferences it to fetch 10, and then increments the pointer to the next element. 
    - Therefore, the first printf outputs 10. By the time the second printf runs, ptr points to the second element, so *ptr outputs 20.

Q2. Correct Answer: A (6 6)
    - TRAP EXPLAINED: 
      1. *(*(arr + 1) + 2) is exactly equivalent to arr[1][2], which maps to Row 1, Column 2. In 0-indexed terms, Row 1 is {4, 5, 6}, and column 2 is 6.
      2. *(*arr + 5) accesses the multi-dimensional array using continuous memory logic. *arr decays into a pointer to the first element (&arr[0][0]). Adding 5 steps linearly over 0, 1, 2 (Row 0) and 3, 4, 5 (Row 1). Index 5 corresponds to matrix[1][2] which is also 6.

Q3. Correct Answer: D (Buffer overflow / Runtime crash due to memory corruption)

      - int *const ptr2 declares a constant pointer to an integer. You can change the value at the address (Line 4 is valid), but you cannot change the address stored in the pointer (Line 3 fails).

Q5. Correct Answer: A (16 10)

    - sizeof counts every byte in the literal token: 'C', '-', 'L', 'a', 'n', 'g', 'u', 'a', 'g', 'e', '\0' (as text characters inside the literal), 'Q', 'u', 'i', 'z', and the automatic trailing '\0'. Total 16 bytes.
    - strlen processes characters linearly and stops scanning at the very first absolute null-terminator it encounters. The string literal engine evaluates '\0' inside the array as a true null byte character, stopping strlen at 10 bytes ("C-Language").

Q6. Correct Answer: B ([Dennis])

Q7. Correct Answer: A (3)
    - TRAP EXPLAINED: Pointer arithmetic is scaling-aware. When you subtract two pointers of the identical data type (p2 - p1), C does not return the difference in raw byte numbers. Instead, it returns the total number of data elements fitting between those addresses: 4 - 1 = 3.

Q8. Correct Answer: B (4 5)

Doing ptr++ moves the pointer forward by an entire block of 3 integers, meaning it now points directly to Row 1 ({4, 5, 6}). Thus, elements at indices 0 and 1 of that array are 4 and 5.

Q11. Correct Answer: B (4)

Q15. Correct Answer: B (matrix[2][0])
     - TRAP EXPLAINED: C handles matrix configurations via Row-Major Order. Row 1 elements fill indices [1][0], [1][1], [1][2], [1][3], and [1][4]. The immediate physical memory location following the final column item of Row 1 is the starting item of Row 2: matrix[2][0].

Q16. Correct Answer: B (20)

Q18. Correct Answer: C (Compilation Error: Dereferencing a void pointer)
     - TRAP EXPLAINED: A void* pointer is a generic pointer with no associated data type. Because the compiler does not know what type of data it points to, you cannot dereference a void pointer (*vptr) directly without first typecasting it to an explicit data type pointer like (int*).

Q19. Correct Answer: B (12 8)

     - Conversely, &arr creates a pointer to an array of 3 integers. The size of *any* address pointer on a 64-bit target system is fixed at exactly 8 bytes.
